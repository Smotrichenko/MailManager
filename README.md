# **MailManager**

## 📋 *Описание*
MailManager — веб-приложение на Django для управления email-рассылками.

Сервис позволяет пользователям создавать получателей, шаблоны писем и рассылки, запускать отправку писем вручную и отслеживать статистику успешных и неуспешных отправок. В проекте реализованы регистрация с подтверждением email, восстановление пароля и разграничение прав доступа между пользователями и менеджерами.


## 🎯 *Функциональные возможности*

### 👤 **Пользователь**
- регистрация и вход в систему;
- подтверждение email;
- восстановление пароля;
- управление **своими**:
  - получателями;
  - письмами;
  - рассылками;
- запуск рассылок вручную;
- просмотр статистики по своим рассылкам.

### 👨‍🎨 **Менеджер**
- просмотр всех пользователей сервиса;
- блокировка пользователей;
- просмотр всех рассылок и получателей;
- отключение рассылок других пользователей;
- редактирование и удаление чужих данных запрещено.

## 💡 *Какую задачу решает проект*
Проект автоматизирует управление email-рассылками:
- хранит базу получателей
- позволяет создавать шаблоны писем
- позволяет формировать и запускать рассылки
- показывает статистику успешных и неуспешных отправок
- реализует разграничение прав доступа для разных ролей пользователей


## 🔔 *Сценарий использования*
1. Пользователь регистрируется и подтверждает email.
2. Создаёт получателей рассылки.
3. Создаёт шаблон письма.
4. Формирует рассылку и связывает её с получателями.
5. Запускает рассылку вручную.
6. Просматривает статистику отправок в интерфейсе.

## ⚙️ *Установка и запуск*
1. Клонируй репозиторий:
```
git clone git@github.com:Smotrichenko/MailManager.git
cd MailManager
```
2. Установи зависимости через Poetry
```
poetry install
```
3. Настроить переменные окружения
```
cоздать .env файл и указать необходимые параметры подключения к базе данных и почтовому серверу.
```
4. Выполнить миграции
```
python manage.py makemigrations
python manage.py migrate
```
5. Создать суперпользователя
```
python manage.py createsuperuser
```
6. Запуск сервера
```
python manage.py runserver
```
