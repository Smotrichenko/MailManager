# **MailManager**

## **Веб-приложение для управления email-рассылками**

## **Описание**
MailManager — это сервис, который позволяет пользователям:
- создавать получателей рассылок,
- создавать шаблоны писем,
- формировать рассылки,
- отправлять письма вручную,
- отслеживать статистику успешных и неуспешных отправок.

Проект поддерживает регистрацию пользователей с подтверждением email, разграничение прав доступа и роли менеджеров.

## **Функциональные возможности**

### **Пользователь**
- регистрация и вход в систему;
- подтверждение email;
- восстановление пароля;
- управление **своими**:
  - получателями;
  - письмами;
  - рассылками;
- запуск рассылок вручную;
- просмотр статистики по своим рассылкам.

### **Менеджер**
- просмотр всех пользователей сервиса;
- блокировка пользователей;
- просмотр всех рассылок и получателей;
- отключение рассылок других пользователей;
- редактирование и удаление чужих данных запрещено.

## **Технологии**
---
- Python 3.13
- Django (включая Django ORM)
- PostgreSQL
- Bootstrap
---

### **Установка и запуск**
1. Клонируй репозиторий:

```
git clone git@github.com:Smotrichenko/MailManager.git
```
2. Установи зависимости через Poetry
```
poetry install
```
3. Выполнить миграции
```
python manage.py makemigrations
python manage.py migrate
```
4. Создать суперпользователя
```
python manage.py createsuperuser
```
5. Запуск сервера
```
python manage.py runserver
```
